# ISI V2 (Industrial Security Integrated)
Website: https://isi-v2.vercel.app/

## Project Overview
ISI V2 is a modern, high-performance web platform for Industrial Security Integrated, featuring comprehensive coverage of security capabilities, integrated facility management, advanced analytics, enterprise verticals, and the ISI Academy & C-DAC MEPZ training programs.

## Key Features & Updates
- **Dedicated Academy & Course Benefits:** Complete, authentic breakdown of learning outcomes, acquired skills, practical labs, career pathways, intended audiences, and prerequisites for all C-DAC MEPZ programs and ISI Academy tracks.
- **Responsive TrustBar (No Scrollbar):** Clean, seamless cross-browser display without unwanted horizontal scrollbars.
- **Optimized Production Build:** Fast Vite + React 18 SPA architecture with lazy loading, Brotli compression, and comprehensive Apache (`.htaccess`) & Vercel (`vercel.json`) routing fallback.
- **Secure Lead Capture & Integrations:** Resilient forms with fallback hooks for Jira and Google Sheets CRM sync.

## Build and Preview
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Lint code
npm run lint

# Check TypeScript types
npx tsc --noEmit

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
